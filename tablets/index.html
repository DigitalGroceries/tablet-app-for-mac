Supported Wacom tablets

Tablet support improves once a week, in that week's app update, so check back once a week to see if your tablet has become fully supported. Each tablet gets worked on, but not every one will end up fully supported. Some can only be improved, but this can be confirmed and improved only with real user feedback for the specific Wacom tablet models. Each weekly update says exactly what changed for which tablet. How often updates come, and how good they are, depends on the voluntary tips we get from happy users who support the project.

These are all 94 Wacom tablets the app's driver knows, with the same support level the app shows when you click Supported tablets.

65 Supported, 3 Has Quirks, 26 Missing Features. The list and support levels come from OpenTabletDriver 0.6.8-rc1, the driver inside Version 15.

  • Supported: all tablet functions work.
  • Has Quirks: the functions work, but one behaves oddly or needs a workaround (see Notes).
  • Missing Features: some tablet functions don't work yet (see Notes).

Your tablet's model number (for example PTK-440) is on the label on the back of the tablet. Only the Wacom PTK-440 has been tested with this app. If you use another one, please tell us how it works.

Version 16 adds touch strips on Intuos3 and older Cintiqs, the Cintiq 13HD centre button, the right ring direction on the 2017 Intuos Pro (PTH-460, PTH-660, PTH-860), the Bamboo Fun ring and the Wacom CTK-4120, not tested on these tablets yet. This list shows the support levels of Version 15 until these are confirmed. What is new.
