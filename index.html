Your Wacom tablet, set up the Wacom way.

A free alternative to the Wacom driver for Apple silicon Macs. Wacom’s last Intuos driver only supports up to macOS 11. The Tablet App for Mac takes over from there, and brings back to life your trusted Wacom tablets.

Newer Wacom tablet? You can use this app instead of Wacom’s driver too. It already knows most current models. We never drop a tablet because it’s old, and if something breaks, we’ll do our best to fix it. We value your hard-earned money and stand against planned obsolescence.

The Tablet App for Mac is laid out like the original Wacom app interface, so there is nothing new to learn. Tested with a Wacom Intuos4 on macOS 27 Golden Gate on an Apple silicon Mac.

ATTENTION: TO INSTALL IT, FOLLOW THESE STEPS

The two permissions (Input Monitoring and Accessibility) are needed only at the first installation; the app guides you. From Version 18 on, updates keep them with nothing to do.

Updating from Version 17 or older: once, in System Settings › Privacy & Security › Input Monitoring and Device Control and Data Access (called Accessibility on older macOS), remove the old Tablet App for Mac entries with −, add the app with + and switch it on.

If the Wacom driver is installed, remove it first with Wacom's own uninstaller (Applications › Wacom Tablet › Wacom Tablet Utility), then restart your Mac.

  1. Open the downloaded file (Tablet-App-for-Mac.dmg), and drag Tablet App for Mac onto the Applications folder.
  2. Open the app from Applications. If Not Opened appears, click Done, not Move to Bin.
  3. Open System Settings › Privacy & Security, scroll down to Security and click Open Anyway.
  4. macOS asks once more. Click Open Anyway, not the blue Move to Bin button.
  5. Confirm with Touch ID, or click Use Password… and enter your Mac login password.
  6. In System Settings › Privacy & Security › Input Monitoring, switch on Tablet App for Mac. This lets the app read your pen.
  7. In System Settings › Privacy & Security › Device Control and Data Access (called Accessibility on older macOS), switch on Tablet App for Mac. This lets the pen move the pointer.
  8. Quit the app and open it again.

Tip: if the pen still doesn't move the pointer, select Tablet App for Mac in those two lists, remove it with −, add it again with +, then reopen the app. Need more help? See the user manual.

What is new in Version 27

  • Radial menu transparency is real. Menu transparency now makes the menu itself see-through, so you can see your picture underneath. It goes from 0 to 60 % (default 40 %); 60 % is the most, so the slice names stay readable even over a white page. Overlapping parts of the icons no longer look brighter.
  • Menu size from 1 to 10. Menu size has a number box you can type in, like Menu transparency, and the two boxes line up. 1 is the smallest menu and 10 the largest, the same sizes as before.
  • An open menu follows the sliders. With the radial menu open, moving Menu transparency or Menu size changes it at once; you don't have to close it first.
  • The Pen page picture is the real size. Radial Menu Settings on Tablet › Pen shows the menu exactly as big as the one your pen opens, with the sliders below it. Click one of the four centre icons (×, pencil, circular arrow, hand) in the picture to read what it does.
  • Messages next to the menu. “Edit the slice you tap next” and confirmations such as “Selection copied” now appear right next to the radial menu, on a solid background that is easy to read.
  • Pencil with the mouse. After clicking the pencil, clicking a slice with the Mac mouse opens that slice’s editor too.
  • “Saved” where you can see it. Confirmations such as “Settings saved” appear over the app’s own window, not over whichever app was in front.
  • Stuck mouse buttons: when the app stops or restarts the driver, the driver now lets go of any held mouse button before it quits (issue #73).
  • Translations: the new texts are in all 8 languages, with wording fixes in Bulgarian, German, Spanish, French and Russian.
  • Known, to be fixed in Version 28: if you open the app from the disk image and then the copy in Applications, the second one may say “Not connected to driver”. Quit every copy, then open only the one in Applications.

Version 26

  • Radial menu. Press a pen button set to Radial menu (pen button 2 by default on a new install, after Restore factory settings or Revert to default) and an 8-slice pie opens around the pen. Tap a slice with the pen tip to run it (Undo, Redo, Copy, Paste, Cut, Select all, Zoom in, Zoom out by default); hold the button to tap several slices. It also works with the Mac mouse: click a slice, drag the edge to move the menu, close it with the centre X. The four centre buttons are Close, Edit (pencil), Restore and Move (hand). Each app can have its own menu; Menu size and Menu transparency (default 40 %) are in the editor.
  • Radial Menu Settings on the Pen page. The radial menu picture sits between the pen drawing and Button 2 / Button 1; click it to edit the menu of the selected app. The editor fits small windows (the pie scales, then the area scrolls). While you pick a slice to edit, a hint is shown on the menu, and a short message such as “Selection copied” confirms each slice that runs. In Scribble, radial Undo and Redo act on your strokes.
  • Touch Ring: Scroll. A ring mode can now be set to Scroll: turning the ring scrolls like a mouse wheel in every app (clockwise = down), with a Speed slider.
  • Relative (Mouse-like) mode: click, click-and-drag and Double Click now work; a pen button set to Double Click clicks where the pointer is and no longer sends the pointer to the corner of the screen. The choice is now named “Relative (slow / no mouse-like speed-up)” with a line that explains it, and Position smoothing (0–10) is on the Pen page.
  • Stuck mouse buttons: a left button held by the pen is now let go when the tablet is unplugged, the driver stops, you press Reset or you use Double Click, and the physical mouse left button works again after a pen button is set to Double Click (issue #73).
  • Smoother fast curves (Pen page, Off by default) adds smooth in-between pen points, so fast curves show fewer flat pieces in apps that join points with straight lines.
  • Pen page: Double Click Fix and a Default button now work per application. Move pen to zoom and Move pen to pan and zoom are new Scroll-tab choices for a pen button.
  • Save as default, Revert to default and Restore factory settings sit next to Save and Revert to saved. Restoring factory settings also resets each ExpressKey and Touch Ring On/Off switch and your per-app tables.
  • Filters tab: plugin filters such as Antichatter show Off and On and keep their choice after you quit and open the app.
  • ExpressKeys: All buttons with Off / On, and an On/Off item in each key’s ••• menu. On an Intuos4 (cable) the ExpressKey screens show what each key does.
  • Help when something is wrong: one Troubleshooting box in Settings (restart the driver, diagnostic report, reset permissions); the “tablet not found” page says what to try; setup says in one line why macOS asks for each permission; the diagnostic report lists the mouse and keyboard.
  • Pen taps activate the tapped app faster (no more 1-second delay when Notification Center sat on top), the app checks for updates at every start, and a read-only old copy of the plugin is replaced when you update.
  • Translations and manual: the texts that were still English are translated in Bulgarian, German, Spanish, French, Japanese, Russian and Chinese, and the manual covers every Version 26 feature.

Requirements

  • A Mac with Apple silicon.
  • macOS 15 or later.
  • The tablet driver, built on OpenTabletDriver (included).
  • Input Monitoring and Accessibility permissions (Accessibility is called Device Control and Data Access on macOS 27).
  • Uninstall the Wacom driver first, as both can't run at once.
