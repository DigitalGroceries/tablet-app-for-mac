# Screenshot slots: button → result pairs

One shot per control and its effect: the button and what it does must both be visible in the same image. Take them on the Mac in this order, in one pass, with the PTK-440 connected and R18 installed. Save each file under its ID as the name (for example `05-pen-tip-feel-customise.png`) in one folder; the site and manual pick them up by name.

Crop: **W** = whole window (1200 × 800 window size, PNG, Retina 2×). **R** = region: the control plus its effect, at least 800 px wide at 2×, about 16:10. **M** = menu or popover open: include the button it opened from.
Unless a shot says otherwise, use the Graphite theme and the default settings.

Slot status: the site and manual hold a box render in each slot until the Mac PNG replaces it. Site slots: S1 home hero, S2 home overview; Help uses the chapter IDs below.
