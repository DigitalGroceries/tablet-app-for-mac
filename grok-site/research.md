Fetched today: opentabletdriver.net, rectangleapp.com, iina.io, alt-tab-macos.netlify.app, keepachangelog.com/en/1.1.0, obsidian.md/changelog. The others are from known structure of those sites, not fetched today.

Search later, when the manual exists (client-side, no service). |

Common to all: one consistent top nav, a footer with licence, no external fonts needed.

## What we built
- Static HTML and one CSS file, generated by tools/build_site.py; GitHub Pages serves docs/. No JavaScript, tracking, external fonts or CDNs.
- Dark only, text no brighter than #E4E4E4, visible focus outlines, skip link, lang="en-GB", headings in order, responsive down to 360 px.
- Home: icon, one-liner, download button (GitHub Releases), requirements, facts list.
- Releases: Keep a Changelog layout; versions grouped Added / Changed / Fixed, from the build history with commit noise removed.
- Help: chapter sidebar, "Manual coming with R18".
- Source: repository, what it is based on, how to build.
- Credits: thanks, a licence table, every full text in a collapsible section.
